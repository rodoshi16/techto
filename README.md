# Tangerine × Sage Demo

Mobile-first demo of Tangerine banking UI with Sage (proactive AI) and Sora (voice).

## Run

npm install && npm run dev

Open http://localhost:5173

## Demo flow

1. Overview — accounts, bills, Sage insight banner
2. Tap Ask Sage — proactive briefing speaks first
3. Use chips or chat — spending breakdown, limits, subscriptions
4. Sora — voice mode from Sage header (ElevenLabs-ready)
